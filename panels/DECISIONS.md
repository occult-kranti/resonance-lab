# Three adaptive panels

These panels are separate AI model-agent reviews, not human experts or historical figures. Six roles worked with the same nine checkouts: software architecture, acoustics/DSP, research curation, independent discourse/evidence criticism, interface curation, and device/metrology review. The root agent moderated and built the host interface. All agents use the session's model; no external provider or licensed professional endorsement is claimed.

## Round 1 — choose the experiment and build the artifact

**Baseline:** resonance-lab f6cf8c3fed3cf5ba10c1d73da8974e282aa397d2 had an unfinished simulator entry importing missing modules; eight other repositories had substantial, incompatible tools. Evidence: source reads from all repositories, original build graph and route registries.

**Accepted:** use resonance-lab as host; preserve all other source trees. Native image/model/record modules plus explicit mounted application handoffs. Maintain read-only repository facts; no invented GitHub, agent, or container telemetry. Keep calendars/charts out; integrate the sigil surface only. Repository source provenance differs from scientific validity. Paper abstracts, full text, cultural records and inaccessible leads retain distinct statuses. User-added device scope uses passive energy-accounted models and optional disclosures.

**Rejected:** automatic unique-frequency extraction from photos; similarity-as-alien-origin classification; iframe playback with hidden independent transports; deleting or rewriting mature DSP engines; claiming free energy from voltage magnification; treating blocked Reddit requests as community findings.

**Artifact produced:** native React workspace, nine-project scanner/service/Compose configuration, image candidate matcher, room model, PCM/WAV transport, local study tracker, research collection and optional RLC device bench. First build: setup-logs/integration-build-r1.log. Initial tests: 12 passing mathematical/DSP tests.

## Round 3 — revised candidate and acceptance

Independent round3-audio, round3-discourse, round3-research and round3-devices records review the changed candidate, with exact file identities where recorded. Root verifies the compiled candidate in Chromium, including invalid input, actual WAV downloads, audio stop, cleared catalogue transfer, notebook persistence, responsive layouts and the existing Brainwave board. Architecture validates read-only API and static mounts; container runtime evidence is recorded separately. No failed browser attempt is counted as a pass.

Known limits accepted: bounded selected corpus, image matching is an exploratory geometric comparison, membrane not material plate model, all architecture inputs are assumed, no new real apparatus measurements, no biological/alien-origin conclusion, no approved Reddit corpus, independent browser-tab audio, no claim that container presence is a deployed fleet. The new host replaces only the broken entry; unfinished legacy simulator modules remain in source and are outside the new entry's TypeScript graph. Publication is not part of this local delivery.
