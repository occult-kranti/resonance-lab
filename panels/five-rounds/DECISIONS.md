## Delivered scope

- One selected-plan interface with compact record selectors, supported plan/elevation/flow projections, original drawings, metre/millimetre display, drawing zoom, component inspection and optional detail panels.
- Explicit geometry scenarios for coil-face spacing and witness position. The scenario changes drawing coordinates only; it does not infer new inductance, mutual coupling, calibration or device output.
- Durable local drafts tied to the record, geometry, contract and asset source identities. A changed source blocks restoration; corrupt or unavailable storage is reported without silent replacement. The integrated notebook records documentation scenarios separately from measurements.
- Eleven detailed study packet sets: annotated vector drawings, additional supported projections, source/scenario JSON, readable HTML, Markdown and rendered PDFs. [Open the packet index](blueprint-packets/README.md).
- Sixty-four context-scoped terminology entries and eight equation cards. Every one of the current frozen R1/R2/R3 contract's 60 declared state/parameter fields is bound to its original value, meaning, unit and convention: 26 + 16 + 18. This is not a claim that every token in every upstream document has been normalized.

The inventory remains 15 proposal IDs, 13 active and 2 excluded, represented by three Newton–Tesla setup families and eight Atlas drawing views. Eleven drawing records do not mean eleven completed devices. Chronology and astrology tools remain outside this blueprint scope.

## Scientific and operational boundaries

Written dimensions describe source-stipulated geometry or explicit annotations. Missing turns, wire gauge, insulation, component ratings, material grades and instrument calibration remain unspecified. Source reading depth is shown as recorded, without claiming new primary-source verification.

The coupled numerical fixture uses peak-amplitude phasors; the host RLC example uses RMS inputs. The explanations preserve that distinction. Optical rays are the frozen source projection, not a newly validated optical solver. Atlas flow drawings do not gain dimensioned projections when the source supplies none.

These are explanatory research blueprints, not manufacturing-certified construction plans. No physical free-energy, antigravity, alien-origin, physiological or monument-frequency result was established. Existing image matching, pitch mapping and assumed-room listening retain their explicit model boundaries.

No Git push, public deployment or environment publication is part of this sequence. Saved repository selection is unchanged; sibling source work is preserved.

## Final review evidence

All 60 named packet-file hashes were checked independently, including 16 source-supported SVG projections and eleven actual PDFs. All 60 frozen contract values matched their source fields. Actual desktop/mobile browser workflows, draft conflict recovery, keyboard help and print-row repairs were checked.
