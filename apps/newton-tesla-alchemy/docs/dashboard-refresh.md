# Reading desk and shared workbench

Baseline: the repository contained a README and four Markdown dossiers, with no HTML dashboard. The new `index.html` is a read-oriented entry point, not a rewrite of the source archive. Its local subject filter, named reading paths and original-text reader use only those four actual files. Text is rendered through `textContent`, preserving labels and citations rather than executing or silently rewriting Markdown.

The evidence-label guide describes how the original archive uses its statuses. It does not certify every inherited assertion or imply a fresh source review. No archive chronology, scientific computation, equipment control, upload or health status was invented.

`assets/integration/dashboard-bridge.js` is copied verbatim from the canonical integration module in Resonance Lab. Its optional, collapsed panel uses a current managed release snapshot where available; a standalone user supplies an actual workbench URL rather than following a fabricated published link. Module byte identity and verification outcomes are recorded separately.

The initial implementation was inspected in one batched desktop/mobile browser pass; any correction and confirmation are recorded in `dashboard-validation.json`. Original Markdown research files remain unchanged.
